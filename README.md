# 📚 Школьная шпаргалка — Telegram-бот

Телеграм-бот с веб-приложением, в котором можно создавать и хранить шпаргалки по школьным предметам.

## Что умеет

- ➕ Добавлять шпаргалки с предметом, заголовком и текстом (формулы, правила, заметки)
- 🔍 Искать по тексту и фильтровать по предмету
- 📋 Копировать содержимое в один тап
- 🗑️ Удалять старое
- 📁 Группировать по предметам (Математика, Физика, Русский… или свой)
- 💾 Хранить локально в браузере **и** синхронизировать с ботом

## Файлы

| Файл | Назначение |
|------|------------|
| `bot.py` | Python-бот на `python-telegram-bot` |
| `cheatsheet.html` | Web App, который открывается внутри Telegram |
| `requirements.txt` | Python-зависимости |
| `tgbotclicker.html` | Старая мини-игра кликер (не относится к шпаргалке) |

## Запуск

### 1. Получи токен бота
Напиши [@BotFather](https://t.me/BotFather), команда `/newbot`.

### 2. Размести `cheatsheet.html` на HTTPS
Telegram Web Apps работают только по HTTPS. Подойдёт:
- GitHub Pages
- Vercel / Netlify
- любой хостинг с SSL

### 3. Настрой кнопку Web App у бота
В `@BotFather`: `/mybots → твой бот → Bot Settings → Menu Button → Edit menu button URL` —
вставь URL твоего `cheatsheet.html`.

### 4. Установи зависимости и запусти

```bash
pip install -r requirements.txt
export BOT_TOKEN="123456:ABC-..."
export WEBAPP_URL="https://твой-домен/cheatsheet.html"
python bot.py
```

## Команды бота

- `/start` — приветствие и кнопка открытия приложения
- `/open` — открыть Web App
- `/list` — текстовый список твоих шпаргалок (сгруппированных по предметам)
- `/help` — справка

## Как работает синхронизация

Веб-приложение хранит данные в `localStorage` браузера (быстро и без сервера).
При добавлении или удалении оно дополнительно отсылает событие в бота через
`Telegram.WebApp.sendData()`, и бот сохраняет копию в локальную SQLite-базу
(`cheatsheets.db`) — её удобно использовать для команды `/list` или для
переноса между устройствами.
